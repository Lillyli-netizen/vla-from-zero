# 从零认识具身智能与机器人操作

以天池「蚂蚁灵波具身大模型挑战赛」（RoboTwin VLA 赛题）为背景，从机械臂、夹爪、相机这些实物出发，逐步学到演示数据、VLA 模型、训练与评测。学习起点按"第一次接触这些东西"安排。

每章先介绍实物和词语，再解释工作过程，然后给一段完整示范或项目里的真实数字，最后做小练习。前面章节假定读者没见过机械臂或仿真器。

实验操作在另一个仓库：[electronics-from-zero](https://github.com/Lillyli-netizen/electronics-from-zero)。本仓库负责"为什么"，那个仓库负责"怎么做"。

## 学习路线

```text
01 → 02 → 03 → 04              （机器人操作：臂、爪、眼、身体）
      ↘ 05 → 06 → 07           （仿真：在哪练、怎么算分）
08 → 09 → 10                    （数据：课本、格式、指令）
      ↘ 11 → 12 → 13 → 14       （模型：VLA 四件套）
15 → 16 → 17 → 18               （训练与提交）
```

每章末尾有练习，答不上来就回对应小节。全部过完再进实验仓库。

## 项目背景数字

学习过程中遇到的数字都来自真实比赛记录，此处集中列出，便于对照：

| 项 | 值 |
|---|---|
| 模型 | LingBot-VLA2 6B（VLM：Qwen3-VL-4B-Instruct；动作专家：36 层 DiT，MoE 32 选 4） |
| 仿真 | RoboTwin 2.0（SAPIEN 引擎），50 个双臂任务，锁定 commit `13c3c47` |
| 数据 | demo_clean 2500 episodes（50 任务 × 50），548893 帧，LeRobot 格式 |
| 训练 | BF16、50000 步、batch 11、约 4.1 s/步、约 57 小时、显存峰值 78.8GB |
| 评测 | demo_clean、20 episodes/任务、共 1000 次 |
| 成绩 | 568/1000 = 56.8%（约 20% 任务 ≥90%，约 24% 任务 ≤35%） |

这些数字是本章内容的实例。概念先行，数字辅助。

## 怎样开始

第一天先读第 1 章，对着机器人操作视频认连杆、关节和末端。读到第 7 章再接触成功率；第 11 章从 VLA 范式进入模型。每次完成一小节，用自己的话复述一遍，再往下读。
