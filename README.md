# 从零认识具身智能与机器人操作

以天池「蚂蚁灵波具身大模型挑战赛」（RoboTwin VLA 赛题）为背景，从机械臂、夹爪、相机这些实物出发，逐步学到演示数据、VLA 模型、训练与评测。学习起点按"第一次接触这些东西"安排。

每章先介绍实物和词语，再解释工作过程，然后给一段完整示范或项目里的真实数字，最后做小练习。前面章节假定读者没见过机械臂或仿真器。

训练与评测操作见 [lingbot-vla-v2-notes](https://github.com/Lillyli-netizen/lingbot-vla-v2-notes)，团队实验流程见 [比赛工作流](https://github.com/Lillyli-netizen/lingbot-vla-v2-guide/blob/main/COMPETITION_WORKFLOW.md)。electronics-from-zero 是电路基础，不能替代 VLA 训练操作手册。

## 使用 Agent 推进实验

有经验的参赛者可以让 Agent 搜索代码、实现候选、解析日志和批量比较，实验仍需绑定清晰的输入、范围和验收证据。每个候选先记录问题、基线代码提交、数据版本、评测协议、预算、输出目录和停止条件。

一条可执行的任务可写成：

> 读取指定配置、模型入口和一份失败记录。提出一个可验证假设，实现最小改动。先检查输入输出、保存与加载和基线等价性。返回代码 diff、运行命令、原始结果路径、逐项指标、耗时及失败样例。

按下面的分工检查 Agent 的结果：

| 环节 | Agent 可以完成的工作 | 复核时看什么 |
|---|---|---|
| 理解任务 | 摘录规则、定位指标实现、列出输入输出 | 规则链接、版本日期、指标实际代码 |
| 数据 | 统计分布、近重复或时序对齐，生成诊断样例 | 固定样本 ID、来源及可复现统计命令 |
| 实现 | 编写基线或单项候选，建立配置 | diff 是否包含额外改动，输入输出是否符合约定 |
| 运行 | 启动已确定的实验，记录资源和异常 | 实际命令、退出码、完整日志与产物 |
| 分析 | 汇总指标、逐类或逐任务失败情况 | 结果能否从原始文件重新计算 |
| 决策 | 根据验证表现和成本给出建议 | 泛化依据、波动、失败实验、预算和复现实测 |

多个 Agent 可分别负责实现与复核，复核使用原始代码和结果。固定一个提交与实验记录入口，协调输出目录和资源，避免同时改同一文件或争抢 GPU。候选推理或训练失败时先定位原因，失败状态写入实验表。

代码比赛用固定划分的验证或 OOF 比较候选。机器人比赛固定任务、seed、指令、执行长度与推理设置，检查闭环成功率和失败回放。表格任务检查来源页、目标区域、结构坐标和计算过程。Agent 的自然语言总结要能对应到这些实际产物。
