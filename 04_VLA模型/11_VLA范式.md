# 11 VLA范式：一个模型从看到动

[目录](../README.md)｜先修：[指令和语言条件](../03_演示数据/10_指令和语言条件.md)｜下一章：[VLM：模型怎样看图](12_VLM模型怎样看图.md)

## 1. 三个字母

**VLA Vision-Language-Action**，视觉-语言-动作模型。输入是视觉（图像）和语言（指令），输出是动作。端到端一个网络完成从感知到控制，中间没有手工拆分的"识别→规划→控制"环节。

传统机器人管线里，这三个环节各自建模、各自出接口。VLA 把它们压进一个模型，靠演示数据端到端训练。

## 2. 灵波比赛的模型

比赛基座是 **LingBot-VLA2 6B**，总参数量 6375.9M、每步激活 5186.8M。它由两大件组成：

| 组件 | 模型 | 职责 |
|---|---|---|
| VLM | Qwen3-VL-4B-Instruct | 看懂图像和指令 |
| Action Expert | DiT（扩散 Transformer） | 把"看懂"的东西变成动作 |

一句话概括分工：VLM 负责"看懂"，DiT 负责"动手"。两个组件内部如何配合，分别在后面三章展开。

## 3. 与传统控制管线的对照

| | 传统管线 | VLA |
|---|---|---|
| 感知 | 目标检测、位姿估计等专用模块 | VLM 直接读图 |
| 规划 | 运动规划算法（RRT 等） | 隐含在模型输出里 |
| 控制 | 轨迹跟踪控制器 | 直接输出关节角 |
| 改进方式 | 逐模块调参数 | 补数据、重训练 |

VLA 换来的灵活性是：换任务改指令即可，重新采集演示再训练。代价是：数据量决定上限，模型内部的过程没有显式接口可查。

## 4. 6B 意味着什么

参数量 6B（60 亿级）决定了两件事：一张 80GB 显卡刚好装得下全量微调（实际显存峰值约 78.8GB）；推理一次的计算量要求动作按块生成以摊薄开销。这解释了后面"精度"和"动作块"两个章节的存在。
