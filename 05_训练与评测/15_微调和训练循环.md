# 15 微调和训练循环：模型怎样从数据学会

[目录](../README.md)｜先修：[动作块和执行](../04_VLA模型/14_动作块和执行.md)｜下一章：[精度显存和batch](16_精度显存和batch.md)

## 1. 微调

**微调 fine-tuning** 指拿预训练好的模型，在自己任务的数据上继续训练。基座已在海量图文上学过"看懂世界"，微调只教它"这个机器人、这 50 个任务该怎么做"。相比从零训练，微调需要的数据量小得多。

## 2. 训练循环

每个训练步做同一件事：

```text
取一批样本 → 模型输出预测动作 → 与数据里的真实动作比差（loss）
→ 反向传播算梯度 → 优化器更新参数 → 下一步
```

**优化器步 optimizer step** 完成一次参数更新，可能累积多个 micro-batch；**epoch** 指全部数据完整过一遍。使用全局有效 batch 且均匀采样时，可以用优化器步数 × 全局有效 batch ÷ 可采样训练项数估计数据遍历次数。动笔算这个等式是动手前的必做检查。

比赛最终版：50000 步 × batch 11 ÷ 548893 帧 ≈ **1 个 epoch**（官方基线约 93 个）。这个算例假定 batch 11 为全局有效 batch、548893 帧对应可采样项数。动作块、梯度累积、重采样会改变口径。训练不足只是待验证假设，需固定其他条件比较多个训练步数的闭环结果。

## 3. 损失在教什么

训练目标是让模型输出的动作块贴近演示数据里的动作。**损失 loss** 度量两者的差，数值随训练下降。比赛最终模型 loss 收敛到约 0.08。

loss 低有歧义：可能是学会了，也可能是把数据背了下来（**过拟合 overfitting**）。判断靠评测，靠 loss 本身会误判。

## 4. 优化器与学习率

**学习率 learning rate** 是每步参数更新的幅度，太大训练震荡，太小进度慢。比赛配置用 Muon + AdamW 两个优化器管理不同参数组，学习率 1e-4 按**余弦衰减 cosine decay** 逐步降到 5e-5：前期大幅更新，后期精细收尾。

调度器状态与模型参数一起保存，断点续训时恢复，否则学习率曲线接不上。

## 5. 练习

已知 548893 帧、batch 11，算出 2 个 epoch 需要多少步。再按 4.1 秒每步估算训练时长（小时）。最后写下：如果只能训一半步数，你会中途做一次评测吗，为什么。
