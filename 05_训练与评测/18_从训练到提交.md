# 18 从训练到提交：最后一段工程路

[目录](../README.md)｜先修：[评测次数和置信度](17_评测次数和置信度.md)｜下一章：无（本仓库完）｜实践仓库：[electronics-from-zero](https://github.com/Lillyli-netizen/electronics-from-zero)

## 1. 提交包里有什么

比赛最终提交一个 zip，约 9.45G：BF16 权重（3 个分片，压缩后约 12G）加推理代码加说明文档。训练用的 74G checkpoint（含优化器状态）只服务于断点续训，提交时剥离，只留推理所需权重。

## 2. 大文件上传

天池超大文件走 **OSS 直传**：ossutil 工具加 STS 临时凭证（1 小时有效），从训练机直接传阿里云对象存储，上传即自动登记为提交。9.45G 实测用时 9.4 分钟（17.9 MB/s）。凭证过期就要重新申请，大文件传输前先把凭证、带宽、磁盘余量三件事确认完。

## 3. 传输完整性

大文件传输后做 **SHA-256** 校验：本地与平台两侧各算一次哈希，一致才确认传输完整。生成候选文件、打包、上传、校验，每一步留下记录，出问题能定位到哪一环。

## 4. 全程时间线复盘

| 阶段 | 主要工作 | 坑 |
|---|---|---|
| 环境搭建 | 两个 conda 环境、flash-attn 源码编译、模型下载 35G | 编译并发要限 MAX_JOBS=2 |
| 数据 | LeRobot v2.1→v3.0 转换 | 转换后就地覆盖，先备份 |
| 首训 | batch=4、10k 步 | 清理脚本误删 checkpoint |
| 评测 | 修复 Vulkan 渲染约 10 小时 | 渲染失败直接 0% |
| 重训 | 大 batch、BF16、50k 步、57 小时 | 显存 78.8/80GB，顶满 |
| 提交 | 全量评测 1000 次、OSS 上传 | STS 凭证 1 小时有效期 |
