# 01 机械臂和自由度：机器人靠什么动手

[目录](../README.md)｜先修：无｜下一章：[夹爪和末端执行器](02_夹爪和末端执行器.md)

## 1. 先认实物

机械臂由几段连杆和若干关节组成。关节让连杆之间发生相对转动或滑动，装在最末端的工具负责接触物体。灵波比赛用的机器人有两只机械臂，任务是抓取放置、开关抽屉、倒水、握手这类日常操作。

| 词语 | 指什么 |
|---|---|
| 连杆 link | 关节之间的刚性杆件 |
| 关节 joint | 让相邻连杆产生相对运动的部件 |
| 基座 base | 机械臂固定不动的部分 |
| 末端 end-effector | 装在机械臂最前端、直接接触物体的工具 |

## 2. 自由度数关节

**自由度 degrees of freedom** 指可以独立控制的运动方向数。数一遍关节就得到它：每个能独立动的关节算一维。常见机械臂有 6 或 7 个旋转关节，加上夹爪开合，整机自由度就是 7 或 8。

两只机械臂各自独立控制时，自由度按臂分别计算，动作向量把两臂排在一起。这一点决定了后面所有模型输出的维度。

## 3. 关节角确定整条臂的形状

给每个关节一个角度，整条臂的形状就定下来了，末端也跟着到达一个确定位置。这组角度叫**关节角 joint angles**，按关节顺序排成向量，例如：

```text
[joint1, joint2, joint3, joint4, joint5, joint6, gripper]
```

反过来，给定想要末端到达的位置，也可以算出各关节该转多少度。前者叫正问题，后者叫逆问题。逆问题可能有多个解，控制程序从中挑一个用。

## 4. 灵波项目里的具体用法

比赛的演示数据和模型输出里都带关节信息。数据记录的是每个控制周期各关节的实际角度；模型学习的是每个周期该输出什么角度。机器人按固定频率接收这串角度并执行，一个周期约零点几秒。

夹爪通常单独占一维，数值表示开合程度，与关节角度放同一个向量里一起发送。

## 5. 练习

找一段灵波比赛的机器人操作视频，暂停三次，每次说出：哪几段是连杆、哪个部位是关节、末端装的是什么工具。再数一遍这只臂有几个关节，说出对应自由度。
