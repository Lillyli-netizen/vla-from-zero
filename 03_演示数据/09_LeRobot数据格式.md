# 09 LeRobot数据格式：演示数据怎样存

[目录](../README.md)｜先修：[演示数据长什么样](08_演示数据长什么样.md)｜下一章：[指令和语言条件](10_指令和语言条件.md)

## 1. 格式解决什么问题

548893 帧的图像、关节角、动作要按统一规则存盘、索引、读取，训练代码才能按批取数据。**LeRobot 格式**是机器人操作数据的事实标准之一，比赛官方用它存储演示数据。

## 2. 目录结构

一个 LeRobot 数据集是一个文件夹，核心内容：

| 文件/目录 | 存什么 |
|---|---|
| 元数据文件 | 总帧数、总 episode 数、帧率、机器人描述、相机列表 |
| 视频文件 | 每个相机一段压缩视频，按 episode 切分 |
| 表格文件 | 每帧的关节角、夹爪、动作、时间戳等数值列 |
| episode 索引 | 第 i 条 episode 对应哪些帧、哪段视频区间 |

图像体积大，按视频编码存储（整段连续帧压缩），数值列按表格存储。读一帧时按索引定位到视频的时间区间解码。

## 3. 版本差异

比赛数据是 **v2.1** 格式，官方脚本把它就地转换成 **v3.0**。两个版本对"视频怎么切、索引怎么排"的约定不同，转换不改变内容，只改组织方式。训练代码按 v3.0 读取。

## 4. 取一条训练样本的路径

训练时每一步从数据集里取一小批帧。路径是：按采样策略选中某 episode 的某帧 → 查索引得到该帧的图像区间和数值行 → 解码图像、读数值 → 拼成（观测， 动作， 指令）三元组。一批几十条这样的三元组构成一个 batch。

## 5. 检查数据集的常用动作

动手训练前先做三件事：确认总帧数和 episode 数与官方说明一致；抽一条 episode 解码几帧图像，确认画面正常；打印一条数值行，确认关节角量纲合理（角度在 ±π 内）。这三步花十分钟，能挡住后面几十小时的无效训练。
